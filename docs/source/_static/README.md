# Static Assets for MagicA Documentation

This directory contains static assets for the documentation.

## Logos

- `magica_logo_whitebg.svg` - Main logo with white background (used in documentation)
- `magica_logo_whitebg.png` - PNG version used as favicon

## CSS

- `custom.css` - Custom styles for the documentation theme

## Usage

The logos are automatically included in the documentation build. The SVG version is used as the main logo, and the PNG version is used as the favicon for browser tabs.
